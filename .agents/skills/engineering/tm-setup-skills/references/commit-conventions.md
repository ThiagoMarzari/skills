# Convenções de commit

- **Formato:** [curta e descritiva | `tipo(escopo): descrição` | outro, descrito abaixo]
- **Idioma:** [português | inglês]
- **Corpo:** [omitido | presente quando a mudança precisa de contexto]
- **Exemplo:** `[mensagem confirmada na entrevista]`
- **Trailer de IA:** proibido — sem `Co-Authored-By`, `Generated with`, 🤖 ou link de sessão
- **Consumidores:** todo commit no repo, pelo bloco `### Commits` do `CLAUDE.md`/`AGENTS.md`, e `tm-delivery` (mensagens de commit)

Preencha os campos com o padrão confirmado na entrevista. Sem este arquivo, `tm-delivery` para e pede `/tm-setup-skills`.
