# Convenções de commit

- **Formato:** [curta e descritiva | `tipo(escopo): descrição` | outro, descrito abaixo]
- **Idioma:** [português | inglês]
- **Corpo:** [omitido | presente quando a mudança precisa de contexto]
- **Consumidores:** `rework-commits` (Etapa 3 — redigir mensagens)

Preencha os campos com o padrão confirmado na entrevista. Sem este arquivo, `rework-commits` usa mensagem curta e descritiva, uma mudança lógica por commit.
