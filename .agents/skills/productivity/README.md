# Productivity

Skills de escrita e manutenção de documentos para agentes. No destino, copie cada pasta `<nome>/` para `.agents/skills/<nome>/` — o bucket não vai junto.

| Skill | Resumo |
|-------|--------|
| `writing-for-agents` | Escreve e revisa documentos consumidos por agentes |
| `handoff` | Leva contexto para outro agente ou sessão |
